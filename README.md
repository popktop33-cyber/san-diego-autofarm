# 💎 San Diego Roleplay Auto Farm

Автоматический фарм для San Diego Border Roleplay с современным GUI интерфейсом.

## 🚀 Возможности

- ✅ **Автофарм Jewelry Store** - грабёж витрин с автоматическим полётом к safe месту
- ✅ **Автофарм Bank** - грабёж тележек с телепортом через стены
- ✅ **Проверка таймеров** - ждёт открытия ограбления
- ✅ **Noclip на сложных участках** - не застревает
- ✅ **Современный GUI** - 3 вкладки (Main, Farm, Cards)

## 📥 Установка

### Способ 1: Loadstring (Рекомендуется)
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/popktop33-cyber/san-diego-autofarm/main/autofarm.lua"))()
```

### Способ 2: Ручная установка
1. Скачай `autofarm.lua`
2. Положи в папку скриптов Real Executor
3. Запусти через Execute

## 🎮 Использование

1. Запусти скрипт
2. Открой вкладку **⚙️ Farm**
3. Нажми **▶ СТАРТ ФАРМ**
4. Скрипт автоматически:
   - Купит нужные предметы (Crowbar, C4)
   - Проверит таймеры ограблений
   - Пройдёт маршруты с noclip
   - Ограбит Jewelry и Bank
   - Повторит цикл

## 📋 Вкладки

- **🏠 Main** - информация об игроке
- **⚙️ Farm** - автоматический фарм
- **🃏 Cards** - игра в дурака (в разработке)

## ⚠️ Требования

- Real Executor (последняя версия)
- San Diego Border Roleplay

## 🔧 Настройки

Все маршруты хранятся в `routes.lua` и встроены в скрипт.
